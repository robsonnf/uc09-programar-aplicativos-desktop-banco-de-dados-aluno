UC09 — Programar aplicativos computacionais com integração de banco de dados para desktop

Técnico em Desenvolvimento de Sistemas · Plano de Curso 01/2025 · 5520 minutos na grade

Projeto final da UC09. O projeto final da UC09 é um software desktop com integração completa com banco de dados, construído aula a aula com o que todas as aulas ensinam: requisitos, modelo em objetos, banco com integridade, interface, consultas, importação, arquitetura em camadas, ORM, documentação e executável. Ele é a principal evidência dos indicadores I1 a I4 e é defendido na A31: um projeto completo e bem defendido é o caminho para o melhor resultado na UC. Veja no mapa da UC.

Guia de consultas SQL · Os comandos do MySQL que você usa na UC, cada um com a forma geral, um exemplo no banco dos kits e a tela real do cliente mysql.
