# Percurso — UC09 — Programar aplicativos computacionais com integração de banco de dados para desktop

Técnico em Desenvolvimento de Sistemas · Plano de Curso 01/2025. 31 aulas, 92 horas de encontros.

## Resultado esperado

Programar um aplicativo desktop que integre interface, código e banco de dados, com operações de persistência e consulta, documentação técnica e compilação para gerar um aplicativo executável.

## Conteúdos da unidade

- Conexão com banco de dados: bibliotecas e operações de conexão.
- Manipulação de dados: recursos de linguagem para manipulação de banco de dados, inserção, atualização, consulta e remoção de registros.
- Listagem de Dados: operações com seleções simples e estruturada no banco de dados; comunicação com elementos de interface.
- Operações de carga massiva de dados.
- Orientação a Objetos: padrões de projeto, padrão MVC e boas práticas.
- Validação e depuração de software: debug, detecção e correção de erros.
- ORM (Mapeadores Objeto-Relacional): conceitos, alternativas e aplicabilidade.
- Indicador 3: Elabora documentação de software conforme as funcionalidades e características do aplicativo computacional para desktop a ser codificado.
- Indicador 4: Realiza a compilação do código desenvolvido para desktop visando a criação de aplicação executável.

- A01 — Abertura, ambiente e diagnóstico
- A02 — Requisitos, ética e organização do trabalho

- A06 — Modelagem relacional e SQL essencial

## Fase 3 · Integrar a interface

- A12 — Eventos, callbacks e validação de entradas

- A15 — Sprint CRUD, testes de fluxo e devolutiva

## Fase 4 · Consultar, importar e organizar

## Fase 6 · Validar e distribuir

- A26 — Depuração sistemática, testes e recuperação de falhas

- A30 — Ajustes finais e preparação da defesa
