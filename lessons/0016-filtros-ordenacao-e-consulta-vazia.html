LIKE: o que % e _ fazem com a busca ↗

nome LIKE %s com o parâmetro '%cabo%' encontra os nomes que têm cabo em qualquer lugar. No LIKE, % vale qualquer texto, até vazio, e _ vale exatamente um caractere. Como a comparação do banco kits ignora maiúsculas e acentos (A13), cabo encontra Cabo, e algodao encontra algodão.

O parâmetro protege o SQL: Caixa d'água chega ao banco como texto, e o apóstrofo não fecha nada. Mas o parâmetro não muda o que o LIKE faz com o texto. Se a pessoa digitar _, o padrão vira '%_%', e qualquer nome com pelo menos uma letra passa: a busca devolve o kit inteiro. Por isso, antes de pôr o trecho entre %, escapar_like põe uma barra antes de cada %, _ e da própria barra. Com a barra na frente, o LIKE do MySQL trata o caractere como letra.

A ordem da troca importa: primeiro a barra, depois % e _. Ao contrário, as barras acabadas de pôr seriam dobradas também.

Ordenar: o banco ordena, e a coluna não vem de fora ↗

Quem ordena é o banco, com ORDER BY. Ordenar na janela parece mais fácil, mas a Treeview guarda tudo como texto: ordenado como texto, 10 vem antes de 9, porque o 1 vem antes do 9. No banco, quantidade é INT, e a ordem é a dos números.

O nome da coluna e o ASC ou DESC não podem ir por parâmetro. Com ORDER BY %s, o conector manda 'quantidade' entre aspas: o banco ordena por um texto que é igual em todas as linhas, ou seja, não ordena nada. Então esses pedaços entram no SQL com f-string, mas nunca com o texto que veio de fora: a janela pede quantidade, e consultar_itens procura esse nome em ORDENS, um dicionário com as colunas permitidas. O que não estiver lá é recusado antes de montar o SQL. A direção sai de um if com dois resultados possíveis.

Depois da coluna, ORDER BY também usa o id. Sem isso, dois itens com a mesma quantidade podem trocar de lugar entre uma leitura e outra, e a sincronização faria a lista mudar sozinha.

Colar o que veio de fora

Qualquer texto vira SQL; e o parâmetro, aqui, não ordenaria nada.

cur.execute(f'... ORDER BY {ordem}')
cur.execute('... ORDER BY %s', (ordem,))

Escolher de uma lista

A janela pede um nome; o SQL só recebe colunas conhecidas.

if ordem not in ORDENS:

... ORDER BY {ORDENS[ordem]} {direcao}, id

A lista vazia que explica ↗

Uma lista sem linhas pode querer dizer três coisas: a busca não achou nada, o kit não tem itens ou a leitura falhou. Para quem usa, as três parecem iguais, e a técnica do relato 3 achou que o kit tinha sumido. A janela diz qual é: com busca, Nenhum item com o trecho neste kit, e como voltar a ver todos; sem busca, Este kit ainda não tem itens, e onde cadastrar. A falha de conexão continua no status, como na A13.

A mensagem fica num CTkLabel na mesma célula da grade em que está a lista. Com grid, o widget de cima aparece por cima do outro; grid_remove o esconde e grid o traz de volta para o mesmo lugar, como o Cancelar da A14. Lista vazia não é erro: o aviso vermelho do formulário continua vazio.

Buscar quando a pessoa parar de digitar ↗

Ligar a busca ao <KeyRelease> faz uma consulta por tecla: digitar alicate são sete consultas, e só a última interessa. Com o MySQL, cada uma abre uma conexão.

A saída é adiar. Cada tecla desmarca a consulta que estava marcada, com after_cancel, e marca outra para daqui a 300 milissegundos, com after. Enquanto a pessoa digita, a consulta vai sendo empurrada; quando ela para, só a última acontece. O identificador do after fica guardado, e o destroy da janela também o cancela, como a sincronização da A14.

def fechar(janela):
    # O CustomTkinter agenda tarefas com after (o ícone da barra de título, por exemplo).
    # Cancelar antes de destruir evita avisos de "invalid command name" no fim do teste.

class BancoDeMentira:
    """Guarda kits e itens em listas e registra o que a janela pediu. falhas: {nome do método: exceção}."""

    def __init__(self, kits=KITS, itens=ITENS, resposta=True, nome_novo=None):
        self.kits = list(kits)
        self.itens = copy.deepcopy(itens)
        self.resposta = resposta
        self.nome_novo = nome_novo
        self.pedidos_de_nome = []
        self.kits_criados = []
        self.falhas = {}
        self.pedidos = []
        self.consultas = []
        self.entregues = []
        self.removidos = []
        self.perguntas = []
        self.editados = []
        self.kits_removidos = []

    def _talvez_falhar(self, nome):
        if nome in self.falhas:
            raise self.falhas[nome]

    def listar_kits(self):
        self._talvez_falhar('listar_kits')
        return list(self.kits)

    def listar_itens(self, kit_id, trecho='', ordem='nome', descendente=False):
        """Busca e ordena como o MySQL faria com estes dados: trecho em qualquer parte do nome, sem
        diferenciar maiúsculas; empate pelo id. Guarda cada pedido em consultas."""
        self._talvez_falhar('listar_itens')
        self.pedidos.append(kit_id)
        self.consultas.append((kit_id, trecho, ordem, descendente))
        itens = [i for i in self.itens.get(kit_id, []) if trecho.casefold() in i[1].casefold()]
        coluna = {'nome': 1, 'quantidade': 2}[ordem]
        itens.sort(key=lambda i: i[0])
        itens.sort(key=lambda i: i[coluna].casefold() if coluna == 1 else i[coluna], reverse=descendente)
        return itens

    def criar_kit(self, nome):
        self._talvez_falhar('criar_kit')
        kit_id = max([k for k, _ in self.kits], default=0) + 1
        self.kits.append((kit_id, nome.strip()))
        self.kits_criados.append(nome)
        return kit_id

    def adicionar(self, kit_id, item):
        self._talvez_falhar('adicionar')
        self.entregues.append((kit_id, item.nome, item.quantidade))
        self.itens.setdefault(kit_id, []).append((100 + len(self.entregues), item.nome, item.quantidade))

    def remover(self, item_id):
        self._talvez_falhar('remover')
        self.removidos.append(item_id)
        for kit_id, itens in self.itens.items():
            self.itens[kit_id] = [i for i in itens if i[0] != item_id]

    def editar(self, item_id, antes, depois):
        self._talvez_falhar('editar')
        for itens in self.itens.values():
            for i, (atual_id, nome, quantidade) in enumerate(itens):
                if atual_id == item_id:
                    if (nome, quantidade) != (antes.nome, antes.quantidade):
                        raise ValueError(f'{antes.nome} mudou depois que você leu: agora é {nome} com {quantidade}')
                    itens[i] = (item_id, depois.nome, depois.quantidade)
                    self.editados.append((item_id, depois.nome, depois.quantidade))
                    return
        raise LookupError(f'Item {item_id} não existe')

    def remover_kit(self, kit_id):
        self._talvez_falhar('remover_kit')
        if self.itens.get(kit_id):
            raise ValueError(f'Kit {kit_id} ainda tem itens: remova os itens antes')
        self.kits = [k for k in self.kits if k[0] != kit_id]
        self.kits_removidos.append(kit_id)

    def perguntar(self, texto):
        self.perguntas.append(texto)
        return self.resposta

    def pedir_nome(self, texto):
        self.pedidos_de_nome.append(texto)
        return self.nome_novo

        self.banco = banco or BancoDeMentira()

    def preencher(self, janela, nome, quantidade):
        for campo, texto in ((janela.nome, nome), (janela.quantidade, quantidade)):

INTERVALO_MS = 10_000


class DadosLegados(DadosMySQL):
    def listar_itens(self, kit_id, trecho='', ordem='nome', descendente=False):
        with conexao_banco(self.config) as con:
            cur = con.cursor()
            cur.execute(f"SELECT id, nome, quantidade FROM item WHERE kit_id = {kit_id} "
                        f"AND nome LIKE '%{trecho}%' ORDER BY nome")
            return cur.fetchall()


class JanelaLegada(JanelaItens):
    def ordenar_por(self, coluna):
        linhas = [(self.lista.set(iid, coluna), iid) for iid in self.lista.get_children()]
        linhas.sort()
        for posicao, (_, iid) in enumerate(linhas):
            self.lista.move(iid, '', posicao)

    def _explicar_vazio(self, itens, trecho):
        if itens:
            self.vazio.grid_remove()
        else:
            self.vazio.configure(text='Este kit ainda não tem itens. Cadastre o primeiro no formulário ao lado.')
            self.vazio.grid()

    def sincronizar(self):
        if self._editando is None:
            self.lista.delete(*self.lista.get_children())
            for item_id, nome, quantidade in self._dados.listar_itens(self.kit_atual()):
                self.lista.insert('', 'end', iid=str(item_id), values=(nome, quantidade))
        self.after(INTERVALO_MS, self.sincronizar)


if __name__ == '__main__':
    JanelaLegada(DadosLegados(), perguntar, INTERVALO_MS, pedir_nome=pedir_nome).mainloop()

def consultar_itens(con, kit_id, trecho='', ordem='nome', descendente=False):
    direcao = 'DESC' if descendente else 'ASC'
    cur = con.cursor()
    cur.execute(f'SELECT id, nome, quantidade FROM item WHERE kit_id = %s '
                f'AND nome LIKE %s ORDER BY {ordem} {direcao}',
                (kit_id, f'%{trecho}%'))
    return cur.fetchall()
ordem entra no SQL sem passar por uma lista de colunas permitidas: qualquer texto que chegue ali vira SQL.

Buscar _ ou % devolve o kit inteiro: os curingas não são escapados.

O trecho é colado no SQL pela f-string e permite injeção com apóstrofo.
