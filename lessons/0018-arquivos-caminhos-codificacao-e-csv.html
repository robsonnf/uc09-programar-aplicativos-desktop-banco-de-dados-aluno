A coordenação mandou o estoque dos kits numa planilha, e cadastrar item por item na janela levaria a tarde toda. Bytes, texto e o BOM do Excel ↗

Um arquivo guarda bytes. A codificação é a regra que liga bytes a letras: em UTF-8, ç é o par de bytes C3 A7; em Windows-1252 (cp1252), é o byte E7. Ler um arquivo UTF-8 como cp1252 não dá erro: cada byte vira uma letra, e ç vira Ã§. Ler cp1252 como UTF-8 dá UnicodeDecodeError, porque E7 sozinho não é UTF-8 válido.

No Python 3.14 do Windows, open e read_text sem encoding usam a codificação do sistema, cp1252, e não UTF-8. Por isso, nesta UC, todo arquivo de texto é aberto com encoding explícito. O Excel, ao salvar como CSV UTF-8, põe no começo três bytes, EF BB BF: o BOM, uma marca de que o arquivo é UTF-8. Lido com utf-8, ele vira o caractere \ufeff grudado no kit do cabeçalho; lido com utf-8-sig, ele é descartado se estiver lá.

A planilha da coordenação pode vir de qualquer um dos três jeitos. ler_texto lê os bytes, tenta utf-8-sig e, se der UnicodeDecodeError, decodifica como cp1252 e diz qual usou. Não use errors='ignore': ele apaga letras em silêncio.

CSV não é split ↗

CSV parece só texto separado por ponto e vírgula, mas tem regras: um campo entre aspas pode ter o separador e até quebra de linha dentro, e aspas dentro do campo são escritas dobradas. O split não conhece essas regras; o módulo csv conhece. O Excel em português usa ponto e vírgula, porque a vírgula é o separador decimal; outros programas usam vírgula. conferir escolhe pelo que aparece na primeira linha.

csv.reader recebe um arquivo, ou um io.StringIO com o texto, aberto com newline='', para que ele mesmo trate as quebras de linha dentro das aspas. leitor.line_num diz em que linha do arquivo o leitor está: é o número que vai para o relatório, porque é o que a pessoa vê no editor. Um campo com quebra de linha ocupa duas linhas do arquivo, e o line_num acompanha; um contador feito à mão, não.

Caminhos: a pasta do comando e a pasta do programa ↗

Path('dados/itens_exemplo.csv') é relativo à pasta de onde o comando foi dado, Path.cwd(), e não à pasta do programa. Rodado da raiz do projeto, acha; rodado de outra pasta ou por um atalho, não acha. Path(__file__).resolve().parent é a pasta do arquivo .py que está rodando, onde quer que ele seja chamado; a partir dela, o operador / monta o resto do caminho.

Arquivo que não existe é dito com o caminho completo, resolve(), para a pessoa ver onde o programa procurou. E conferir_planilha.py sai com um código: 0 se tudo está certo, 1 se há erro na planilha e 2 se o arquivo não existe. Outros programas, e a A19, usam esse código para decidir se continuam.

Cada erro com a sua linha ↗

Uma linha errada não para a conferência: ela vira um erro, com o número da linha e a mensagem, e a próxima linha é conferida. As regras são as do domínio, as mesmas do formulário da janela: ItemKit recusa nome vazio, ler_quantidade recusa dez e zero. A planilha acrescenta duas: três colunas, e o mesmo item uma vez só em cada kit, sem diferenciar maiúsculas.

Só a falta do cabeçalho recusa a planilha inteira, com PlanilhaInvalida: sem ele, não dá para saber que coluna é o quê. Linhas em branco, comuns no fim do arquivo, são puladas sem mudar a numeração.

"""A planilha de itens: codificação, separador, aspas, erros por linha e o relatório. Não usa banco nem janela."""
import contextlib
import io
import os
import tempfile
import unittest
from pathlib import Path

import conferir_planilha
from kits.planilha import PlanilhaInvalida, conferir, conferir_arquivo

BOA = 'kit;item;quantidade\nTreinamento Redes;Cabeça de rede;2\nAlmoxarifado;"Fita; preta";3\n'


class TestPlanilha(unittest.TestCase):
    def setUp(self):
        pasta = tempfile.TemporaryDirectory()
        self.addCleanup(pasta.cleanup)
        self.pasta = Path(pasta.name)

    def arquivo(self, texto, codificacao='utf-8', nome='itens.csv'):
        caminho = self.pasta / nome
        caminho.write_bytes(texto.encode(codificacao))
        return caminho

    def nomes(self, resultado):
        return [(l.numero, l.kit, l.item.nome, l.item.quantidade) for l in resultado.linhas]

    # Codificação

    def test_utf8_do_excel_com_bom_le_acentos_e_o_cabecalho(self):
        resultado = conferir_arquivo(self.arquivo(BOA, 'utf-8-sig'))
        self.assertEqual(resultado.codificacao, 'UTF-8')
        self.assertEqual(self.nomes(resultado)[0], (2, 'Treinamento Redes', 'Cabeça de rede', 2))

    def test_utf8_sem_bom(self):
        self.assertEqual(self.nomes(conferir_arquivo(self.arquivo(BOA)))[0][2], 'Cabeça de rede')

    # Complete: a planilha BOA gravada em cp1252 é lida com codificacao 'Windows-1252' e o primeiro item é Cabeça de rede.

    # Separador e aspas

    def test_aspas_protegem_o_separador_dentro_do_nome(self):
        self.assertEqual(self.nomes(conferir_arquivo(self.arquivo(BOA)))[1], (3, 'Almoxarifado', 'Fita; preta', 3))

    def test_virgula_tambem_serve_de_separador(self):
        _, linhas, erros = conferir('kit,item,quantidade\nAlmoxarifado,"Cabo, 2 m",5\n')
        self.assertEqual(([(l.kit, l.item.nome) for l in linhas], erros), ([('Almoxarifado', 'Cabo, 2 m')], []))

    def test_cabecalho_com_maiusculas_e_espacos_serve(self):
        _, linhas, _ = conferir(' Kit ; ITEM ;Quantidade\nAlmoxarifado;Cabo;1\n')
        self.assertEqual(len(linhas), 1)

    # Erros por linha

    def test_cada_erro_vem_com_a_linha_do_arquivo(self):
        texto = ('kit;item;quantidade\nAlmoxarifado;Fita;dez\nAlmoxarifado;;3\n;Cabo;1\n'
                 'Almoxarifado;Cabo;1;sobra\nAlmoxarifado;Alicate;0\n')
        _, linhas, erros = conferir(texto)
        self.assertEqual(linhas, [])
        self.assertEqual(erros, [(2, "'dez' não é um número inteiro"), (3, 'nome deve ser texto não vazio'),
                                 (4, 'falta o kit'), (5, 'tem 4 colunas, e não 3 (confira o separador ; e as aspas)'),
                                 (6, '0 não é maior que zero')])

    # Complete: com Cabo no Almoxarifado na linha 2, Cabo em outro kit na 3 e CABO no almoxarifado na 4, as linhas 2 e 3
    # passam e a 4 vira o erro 'repete CABO no kit almoxarifado, da linha 2'.

    def test_linhas_em_branco_sao_puladas_sem_mudar_a_numeracao(self):
        _, linhas, erros = conferir('kit;item;quantidade\n\nAlmoxarifado;Cabo;1\n;;\n\n')
        self.assertEqual(([l.numero for l in linhas], erros), ([3], []))

    def test_nome_com_quebra_de_linha_entre_aspas_conta_as_duas_linhas(self):
        _, linhas, erros = conferir('kit;item;quantidade\nAlmoxarifado;"Cabo\nlongo";1\nAlmoxarifado;Fita;x\n')
        self.assertEqual(linhas[0].item.nome, 'Cabo\nlongo')

"""Conferência herdada de planilhas. Uso: python conferir_legado.py caminho.csv"""
import sys

from kits.modelo import ItemKit
from kits.regras import QuantidadeInvalida, ler_quantidade


def conferir_legado(caminho):
    linhas, erros = [], []
    with open(caminho) as arquivo:
        cabecalho = arquivo.readline().strip().split(';')
        if cabecalho != ['kit', 'item', 'quantidade']:
            raise ValueError('A primeira linha está errada')
        for numero, texto in enumerate(arquivo, start=1):
            if not texto.strip():
                continue
            kit, nome, quantidade = texto.strip().split(';')
            try:
                linhas.append((kit, ItemKit(nome, ler_quantidade(quantidade))))
            except (QuantidadeInvalida, ValueError) as erro:
                erros.append((numero, str(erro)))
    return linhas, erros

def conferir(texto):
    linhas, erros = [], []
    leitor = csv.reader(io.StringIO(texto, newline=''), delimiter=';')
    next(leitor)
    for numero, campos in enumerate(leitor, start=2):
        kit, nome, quantidade = campos
        try:
            linhas.append((numero, kit, ItemKit(nome, ler_quantidade(quantidade))))
        except (QuantidadeInvalida, ValueError) as erro:
            erros.append((numero, str(erro)))
    return linhas, erros
Depois de um nome entre aspas com quebra de linha, os números dos erros ficam uma linha atrás do editor; leitor.line_num não erraria.

next(leitor) pula a primeira linha sem conferir: numa planilha sem cabeçalho, o primeiro item some sem aviso.

csv.reader com delimiter=';' corta 'Fita; preta' entre aspas em duas colunas, como o split faria.
