Consolidar: as regras da arquitetura viram testes, e a suíte vira um comando

Depois de três aulas separando camadas, o projeto tem regras que só existem na cabeça de quem as escreveu: o controle não importa Tk, a janela não importa o banco. Hoje essas regras viram um teste que lê os imports de cada arquivo. Os mais de cento e cinquenta testes viram uma suíte de regressão com um comando só, em três grupos, do mais rápido ao mais lento, que não para no primeiro problema e diz com o código de saída se o commit pode sair. E um teste que falhou uma vez sem motivo aparente é tratado como defeito: repetido até mostrar a frequência, explicado e corrigido.

A aula continua no projeto da A21. O comportamento do aplicativo não muda. Use dados fictícios.

A regra de arquitetura como teste ↗

A tabela de imports proibidos da A21 é uma regra que ninguém confere: num dia de pressa, alguém importa o repositório na janela para resolver rápido, e as camadas voltam a se misturar sem nenhum teste falhar. tests/test_camadas.py transforma a tabela em teste. O módulo ast lê o arquivo como árvore, sem rodá-lo, e cada nó Import ou ImportFrom diz um módulo importado.

O teste também falha quando aparece um arquivo novo em kits/ sem regra, e quando um arquivo de teste existe mas não está em nenhum grupo da suíte: as duas formas de a regra ficar velha sem ninguém perceber.

Uma suíte de regressão em grupos ↗

Regressão é um defeito que volta, ou que aparece onde já funcionava, depois de uma mudança. A suíte de regressão é o conjunto de testes que prova que nada do que já funcionava quebrou; ela só serve se for rodada sempre, então precisa ser um comando só.

verificar.py roda em três grupos: primeiro os que não usam banco nem janela, que levam segundos; depois os da janela; por último os do MySQL. Um defeito de regra aparece logo, sem esperar janelas e banco. Mas o verificador não para no primeiro grupo com problema: o resumo no fim mostra tudo de uma vez, e quem corrige sabe o tamanho do trabalho.

Problema não é só falha. Um teste que levanta exceção, ou um módulo de teste que nem importa (um arquivo renomeado), aparece no unittest como erro, e erro também impede o commit. O código de saída, 0 ou 1, é o que outros programas leem: um gancho de commit, um script de entrega, a integração contínua.

O teste que falha de vez em quando ↗

Um teste intermitente passa e falha com o mesmo código. Rodar de novo e seguir em frente ensina a turma a ignorar o vermelho, e o dia em que a falha for real ninguém olha. O primeiro passo é medir: verificar.py --repetir 20 NOME roda o teste vinte vezes e diz quantas falhou.

O teste da busca da A16 digitava com focus_set e gerava as teclas logo em seguida. Ele falhou uma vez, num computador carregado, e passou nas seguintes. A causa mais provável: o foco ainda não tinha chegado ao campo quando a tecla foi gerada, e o Tk entrega tecla a quem tem o foco, então a busca nunca acontecia. A correção não é esperar mais tempo, e sim esperar o que importa: o ajudante focar chama focus_force e confere com focus_get até o foco chegar, como o teste de Enter das capturas da A12. Todos os testes de tecla passam a usá-lo.

Na mesma revisão, outro incômodo: as recusas de importação apareciam escritas no meio da saída dos testes. Sem configuração, o logging escreve avisos no terminal. Um NullHandler no registrador do kits/dados.py cala isso quando ninguém configurou o log; o abrir_janela.py continua decidindo o arquivo, e o assertLogs continua capturando.

    'repositorio.py': {'tkinter', 'customtkinter', 'kits.janela', 'kits.controle', 'kits.dados'},
    # Complete: dados.py, controle.py, janela.py, resumo.py, importacao.py e dialogos.py, pela tabela da seção.
    'planilha.py': {'tkinter', 'customtkinter', 'mysql'},
    'modelo.py': {'tkinter', 'customtkinter', 'mysql', 'kits.banco', 'kits.repositorio'},
    'regras.py': {'tkinter', 'customtkinter', 'mysql', 'kits.banco', 'kits.repositorio'},

def importados(caminho):
    """Os nomes de módulo que o arquivo importa, lidos da árvore do código."""
    for no in ast.walk(ast.parse(caminho.read_text(encoding='utf-8'))):
        if isinstance(no, ast.Import):
            yield from (nome.name for nome in no.names)
        elif isinstance(no, ast.ImportFrom) and no.module:
            yield no.module


def proibido(modulo, proibidos):
    return any(modulo == p or modulo.startswith(p + '.') for p in proibidos)


class TestCamadas(unittest.TestCase):
    def test_cada_arquivo_so_importa_o_que_a_camada_dele_pode(self):
        for nome, proibidos in PROIBIDOS.items():
            with self.subTest(nome):
                caminho = RAIZ / 'kits' / nome
                errados = [m for m in importados(caminho) if proibido(m, proibidos)]
                self.assertEqual(errados, [], f'{nome} importa {errados}')

    def test_todo_arquivo_de_kits_tem_regra(self):
        arquivos = {p.name for p in (RAIZ / 'kits').glob('*.py')} - {'__init__.py', 'banco.py'}
        self.assertEqual(arquivos - set(PROIBIDOS), set(), 'arquivo novo em kits/ sem regra de camada')

"""Suíte de regressão herdada. Para examinar: guarde o seu verificar.py (copie para verificar_bom.py), ponha este
no lugar dele, rode os testes rápidos e o próprio script, e devolva o seu."""
import io
import sys
import unittest

GRUPOS = (
    ('sem banco nem janela', ['tests.test_camadas', 'tests.test_verificar', 'tests.test_controle', 'tests.test_dados',
                              'tests.test_planilha']),
    ('com janela, sem banco', ['tests.test_janela', 'tests.test_resumo', 'tests.test_importacao']),
    ('com o MySQL', ['tests.test_repositorio', 'tests.test_retirada', 'tests.test_transferencia', 'tests.test_fontes']),
)


def rodar(nomes):
    suite = unittest.defaultTestLoader.loadTestsFromNames(nomes)
    return unittest.TextTestRunner(stream=io.StringIO(), verbosity=0).run(suite)


def problemas(resultado):
    return [teste.id() for teste, _ in resultado.failures]


def suite_inteira(escrever=print):
    for nome, modulos in GRUPOS:
        resultado = rodar(modulos)
        ruins = problemas(resultado)
        escrever(f'{nome}: {resultado.testsRun} testes, {len(ruins)} com problema')
        for teste in ruins:
            escrever(f'  {teste}')
        if ruins:
            break
    escrever('Fim.')
    return 0


def repetir(vezes, nome, escrever=print):
    falhas = sum(1 for _ in range(vezes) if not rodar([nome]).wasSuccessful())
    escrever(f'{nome}: falhou {falhas} de {vezes}')
    return 0 if falhas == 0 else 1


def main(argumentos, escrever=print):
    if argumentos[:1] == ['--repetir']:
        return repetir(int(argumentos[1]), argumentos[2], escrever)
    return suite_inteira(escrever)


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))

def suite_inteira(escrever=print):
    codigo = 0
    for nome, modulos in GRUPOS:
        resultado = rodar(modulos)
        escrever(f'{nome}: {resultado.testsRun} testes, {len(resultado.failures)} falhas')
        if resultado.failures:
            codigo = 1
    return codigo
